# Stack
> 스택은 후입선출(**Last In First Out, LIFO**) 방식으로 저장하는 선형 자료구조

<br>

✔️ 주요 연산
- `push`: 스택의 맨 위(top)에 데이터를 추가
- `pop`: 스택의 맨 위(top) 데이터 제거 및 반환
- `peek`: 스택의 맨 위 데이터를 제거하지 않고 확인

# Queue

> 큐은 선입선출(**First In First Out, FIFO**) 방식으로 저장하는 선형 자료구조

<br>

✔️ 주요 연산
- `enqueue`: 큐의 뒤쪽(rear)에 데이터 삽입
- `dequeue`: 쿠의 앞쪽(front)에서 데이터 제거 및 반환
- `peek`: front 데이터를 제거하지 않고 확인
